# Crypto Position Sizer

Calculate size from maximum account risk and stop distance. Constrain by volatility, liquidity, leverage, margin, liquidation buffer, and exchange minimum order size.

Show entry, stop, liquidation estimate when relevant, notional value, margin used, account risk, fee estimate, and invalidation condition.

Prefer lower leverage or smaller size when volatility expands.
