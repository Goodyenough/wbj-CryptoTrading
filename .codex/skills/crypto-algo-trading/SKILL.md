# Crypto Algo Trading

Structure systems as exchange adapter, data pipeline, strategy engine, risk manager, order executor, position tracker, and performance monitor.

Separate research, paper trading, and live trading. Never place live orders unless explicitly requested and API keys, venue, permissions, and risk limits are configured.

Handle 24/7 markets, exchange outages, partial fills, rate limits, funding intervals, liquidation prices, and stablecoin collateral.
