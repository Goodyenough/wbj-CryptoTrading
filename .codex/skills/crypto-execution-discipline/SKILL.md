# Crypto Execution Discipline

Before entry, verify setup, regime, position size, stop, liquidation buffer, funding, liquidity, exchange status, and rule compliance.

After entry, prevent unplanned averaging down, widening stops, increasing leverage, revenge trades, and emotional exits. Require a written reason for deviations.
