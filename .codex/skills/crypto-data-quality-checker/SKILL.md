# Crypto Data Quality Checker

Check symbol identity, quote asset, venue, timezone, missing candles, duplicate bars, zero volume, suspicious wicks, stablecoin depegs, contract roll/spec changes, and provider disagreements.

For strategy research, fail closed when data issues can change signals, fees, liquidation, or PnL materially.
