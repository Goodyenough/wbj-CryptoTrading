## Round 1：Claude 回复

### 结论（先给方向）

**方向在机制上自洽，但它建立在一个已经被本项目自己数据削弱了的前提上：20 根突破输不是因为"太晚"，而是它在这两个窗口里就没有（或近似没有）可交易的动能延续 edge。因此首轮最该做的不是 A/B/C/D 任何一个候选，而是一个近乎零成本的"前提诊断"——在现有 C 事件上测"突破前涨幅 → 成交后结果"的斜率。** 如果这个斜率是平的，整个"更早入场"方向应整体否决，转去查退出；如果是负的，才值得预注册一个最小收缩突破候选 D0。

在此之前，我不建议直接把四个条件（6 根 / 1.5×ATR / 20 根量中位数 / 3% 防追高）捆成一个候选——那是"用一个没被证明的假设去包装另一个没被证明的假设"。

---

### 一、先挑战前提：数据并不支持"20 根太晚"这个因果

这是整件事最需要说破的地方。看两窗 C 的表：

| 窗口 | C 净胜率 | C PF | 推论 |
|---|---:|---:|---|
| 早窗 | 37.38% | 0.847 | 胜率 ≈ 37.5% 毛盈亏平衡线，净负几乎全是成本 |
| 近窗 | 34.14% | 0.630 | 胜率**低于** 37.5%，PF 0.63 → 毛期望也是负的 |

关键在近窗：**PF 0.630、胜率 34.14% 意味着 20 根突破在近窗是"负毛期望"**，不是"接近打平被成本吃掉"。这跟"我们只是晚进了一波真实动能"的解释**不兼容**：

- 如果是"晚进了一波真实动能"，成交后应该还有残存的正向漂移，毛期望应≈0 或略正，靠成本转负——早窗正是这样（37.38% ≈ 37.5% 平衡线）。
- 但近窗是**明确低于硬币**：突破后价格倾向于回落（均值回归），而不是延续。买 20 根新高在近窗是一个**反向信号**。

而项目自己的 `breakout_lateness_diagnostic_v1` 也已得出"不能简单断言 20 根过晚是统一主因"——早窗"已涨 5% 后无空间"的 95% 区间 [37.9%, 58.8%] 跨越 50%，在统计上甚至不能确认"已经涨过就更可能没空间"。

**所以：A/B 都在赌"更早 = 更接近动能起点"，但数据更支持"动能起点本身不存在（近窗）或只剩硬币（早窗）"。** 在这个前提没被单独证否之前，把"更早"做成一个四条件的复杂候选，是用没被证明的假设去解释另一个假设。

**唯一的判别证据是"突破前涨幅 → 成交后结果"的斜率**（见第三节），当前没有这个变量。

### 二、问题 1：A 是连贯机制，还是四个事后合理化过滤器的组合？

**结论：A 的"收缩→突破"是连贯机制；"放量"和"防追高"是两个被嫁接的独立假设，其中"防追高"与"收缩"高度冗余。** 拆解如下：

**核心机制（自洽，值得保留）：收缩 → 首次扩张。** 这是经典的 volatility squeeze → expansion（NR7 / Bollinger / Keltner squeeze 一族），有清晰的因果故事：低波动期之后波动率回归上升，突破方向即信号。6 根收缩 + 首次突破 6 根 high 是**自包含的单一概念**（突破参照 = 收缩窗口长度，不必另设数字），自由度为 {6, 1.5×ATR20} 两个数字，可辩护为"一个机制"。

**嫁接假设 #2（独立，应拆出）：放量确认。** 它是"突破被参与度确认"这个**不同**的假设，与"是否在动能起点"无关。首轮不应作闸门，应作连续特征（成交量分位）诊断。

**嫁接假设 #3（独立且≈冗余，应删或改诊断）：防追高 ≤3%。** 12h = 3 根 4h。若前 6 根已收缩，3 根前的收盘 ≈ 当前收盘，`≤3%` 几乎恒成立——它和"收缩"测的是同一件事（"没怎么涨"）。所以 GPT 自己的顾虑"防追高是否重复过滤"是**对的**：它与收缩重叠。要么删掉，要么改成一个与收缩正交的量（例如"突破前 20 根累计涨幅"来直接呼应 96% 那个观察），但首轮建议删。

**还藏着一个第 4 个条件**：`首次`突破的"首次"逻辑（避免连续 K 线重复触发，等价于 C 的"前一根不是自身新高"）。这是状态机细节，不是机制，但要写清，否则会多一批重触发样本。

### 三、问题 2：首轮只允许一个最小步骤，我选"前提诊断 G"，不是任何候选

**推荐：诊断 G（斜率检验），零未来数据，几乎零成本。**

**精确定义**（全在已算好的 C 事件上，650 + 457 笔）：

> 对每个 C 事件，取"突破前涨幅" = `(breakout_close − min_low_prior_20_bars) / min_low_prior_20_bars`（即已有的"此前 20 根最低到突破收盘"口径）。按涨幅分 bin，统计每个 bin 的成交后结果：净 P&L、胜率、48h MFE、favorable-first 率（先到 +5% 还是先到 −3%）。检验**单调性：突破前涨幅越高 → 成交后结果越差？**

**裁决**：

- **斜率为负（单调恶化）**：lateness 因果成立，方向 A/B/C/D 的前提被证明 → **才**预注册 D0 进入下一轮。
- **斜率为平**：lateness 与结果无关 → 整个"更早入场"方向**整体否决**，转去查退出（18.62% 先 SL 后达目标、favorable-first 结构、以及 −3/+5 的不对称，见第四节）。
- **斜率不稳定 / 样本不足**：证据不足，也**不**进入候选建设。

**为什么是它而不是 A/B/C/D**：它一次回答"20 根突破输，到底是不是因为晚"，而这正是 A/B/C/D 全部的共同前提。它在已有事件上做，不引入任何新参数、不占用新窗口、不产生过拟合风险。**如果斜率是平的，A/B/C/D 一个都不用做，方向直接死掉——这是本轮最高性价比的一步。**

**若你坚持必须有候选，fallback = D0（最小收缩突破）**，精确定义（无未来数据）：

- 资格/regime/数据质量/成本闸门：与 C 完全一致。
- 收缩：前 6 根 4h 的 `(max high − min low) ≤ 1.5 × ATR20`。
- 突破：当前已收盘 4h 收盘 > 前 6 根 high 的 max，且前一根自身不是收缩突破（避免重触发）。
- 成交：下一根 4h 开盘（含滑点），taker 费。
- 退出：+5%/−3%/48h，细周期 stop-first，与 C 一致。
- **无放量闸门、无防追高闸门**（放量分位、12h 涨幅作为连续特征记录，不作门）。
- 自由参数：`{6, 1.5×ATR20}` 两个数字，预注册锁定，不许事后扫。

### 四、问题 3：固定 +5%/−3%/48h 是否仍适合隔离入场？

**结论：作为"控制"必须保留，但它不是一个中性的控制——它内置了一个 ≈37.5% 的毛盈亏平衡门槛，而且对收缩突破的回踩结构有系统性误伤风险。正确处理是"保留退出 + 增加入场质量诊断输出"，而不是调退出。**

三点：

1. **−3/+5 的不对称 = 37.5% 毛盈亏平衡线**（3/(3+5)=37.5%，含成本更高）。这意味着一枚硬币入场也会在净收益上表现为负。所以"近窗 C 净 −0.6995%"不能单独读作"入场没 edge"，它可能是"入场 edge 存在但胜率没过 37.5% 门槛"。**"净负"对入场质量是弱信号。**

2. **收缩突破的回踩结构**：挤压后的突破经常先回踩突破位再继续。下一根开盘成交时价格可能已比突破收盘高 1–2%，此时 −3% 的止损很容易在"回踩"时被打掉，之后才涨到 +5%。这会让一个方向正确的收缩突破被 −3% 误杀——**这是"系统性错判"的真实来源**。早窗 18.62% 的"先 SL 后 48h 内仍达目标"就是这个信号的直接证据。

3. **怎么不落入"同时优化入场和退出"**：把退出钉死为控制，但**必须额外输出入场质量诊断**，让"入场坏"和"退出坏"可分离：

   - `favorable_first_rate`：先到 +5% 还是先到 −3%。
   - `48h_MFE` 中位数（成交后最大有利偏移，无未来数据问题，因为 MFE 是 48h 窗口内的事实）。
   - `sl_then_target_48h_rate`：先打 −3% 止损、后 48h 内仍到 +5% 的比例。

   **判定**：若 D 的净收益仍负、但 favorable-first 和 48h-MFE 显著好于 C，且 `sl_then_target` 高——结论是"**入场有效、退出与收缩突破的波动结构不匹配**"，这**不是**"入场没 edge"，而是一个**退出匹配问题**，应作为一张**独立的、预注册的退出实验卡片**（例如 ATR 止损、更宽止损、更长 horizon）另行审批，**绝不在本轮静默调退出**。

### 五、问题 4：最小但严格的支持 / 否定 / 不足标准（反过拟合）

**根本原则：这两个窗口已被反复使用（reference、20 根、多轮诊断），它们现在只能"证伪"和"看形状"，不能"证实"任何候选。** 任何"支持"最多等于"获得进入未使用数据的一次资格"。

- D 在两窗净期望均 ≤ 0；或 D 在两窗都不优于 C（既然机制主张"更早且更好"，在样本内连 C 都不如，直接判死）；
