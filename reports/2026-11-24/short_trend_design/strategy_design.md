# 短期趋势策略设计：48小时结构突破，账户净目标1%

状态：研究设计草案，待执行协议与数据审计；`retest`，不是实盘策略，不修改现有信号。本轮只讨论，没有运行新回测或读取新行情。所有阈值是事前选择，尚无收益或高胜率证据。

后续状态（2026-11-24）：审计与研究协议已完成，详见`research/short_trend/PROTOCOL.md`和`reports/2026-11-24/short_trend_preflight/`。2023–2025已用；真实账户执行证据不足。审计发生已登记的摘要暴露及跨2026冻结JSON整文件载入，不能将本段原讨论阶段声明外推为后续审计零暴露。

## 目标与本次决策

系统目标：顺应短期趋势，多空都可以；盈利单争取使入场时账户总权益净增加1%–2%，同时要求较高盈利胜率、正净期望和有限回撤。

本次只问：**一个明确的较长结构突破方向，能否在未来4小时提供扣成本后、优于同一时点随机方向的优势？** 研究位于“旧ZEC候选失败后的下一项假设设计”阶段。先辨别优势，再讨论部署；本轮不自动开展下一次实验。

- 事实：用户的1%–2%指账户净增长；110USDT账户对应1.1–2.2USDT。原5–8USDT风险是上限，不必用满。
- 观察：此前1H EMA方向加15M短区间突破的四组固定ZEC候选均未通过；既有高波动组即使盈利胜率约70%，平均净收益仍负。
- 假设：更长结构的首次突破可能减少短区间往返噪声，方向信息是否足以覆盖成本未知；扩币可能增加机会，也可能只是增加相关事件。
- 决定：只提出一套主规格和一个同时间随机方向对照；不用新指标或网格挑选救结果。整个2026年行情继续封存。

## 给使用者的一句话规则

**1小时收盘首次突破过去48根小时K线的最高点就研究做多，首次跌破最低点就研究做空；不等回踩。先确定突破失效的止损，再按风险算仓位；账户净赚1%止盈，最迟4小时退出。**

“首次”按下面的收盘条件定义，不是只要盘中摸到高低点就入场。48小时是观察结构的长度，4小时是持仓期限。

## 唯一主规格

设`t`为UTC整点；信号柱是刚完成的`[t−1h,t)`，收盘价为`C(t)`。`H48(t)`、`L48(t)`分别是**不含信号柱**、此前48根完整1H柱的最高价、最低价。`A(t)`为含刚完成信号柱的Wilder ATR14。

| 项目 | 研究规则 |
|---|---|
| 币池 | BTCUSDT、ETHUSDT、SOLUSDT的USD-M永续；历史上市、可交易与流动性需先审计。这是指定小池，不代表全市场。ZEC同规则单独探索，不进入主通过判定。 |
| 做多 | `C(t)>H48(t)`且`C(t−1h)≤H48(t−1h)`。 |
| 做空 | `C(t)<L48(t)`且`C(t−1h)≥L48(t−1h)`。 |
| 入场 | `t+5min`开始的5M柱开盘为市价参考，加实际方向不利滑点和手续费；不等回踩。缺该柱不顺延；系统漏跑后过期事件不追。 |
| 固定止损 | 多：`S=H48(t)−A(t)`；空：`S=L48(t)+A(t)`。入场后不移动，不摊平加仓。 |
| 入场前检查 | 到达时已越过止损则作废；重新核对仓位和计划风险，只允许减量。缺必要数据、数量/最小单要求不满足则跳过并记录。 |
| 计划风险 | `r=min(1.5%×E, 5USDT)`，`E`是该次入场前权益。110USDT时预算1.65USDT，含计划手续费、滑点、0.05%名义的资金费预留；跳空与超预期成本可造成超额实际损失。 |
| 仓位 | 先按结构止损距离反算数量，再受风险与`名义≤2E`约束，最终按历史步长向下取整。面板杠杆倍数不能替代名义敞口或风险计算。 |
| 止盈 | 本版唯一主目标：**扣双边费、滑点及已发生资金费后，净利润达到入场权益1%**。110USDT时目标1.1USDT。2%留作以后独立假设，不在本次选优。 |
| 时间退出 | 从模拟成交时刻起满4小时，以当时5M开盘市价退出；不延长等待回本。 |
| 同时持仓 | 账户层最多1仓；同刻多个可执行信号按固定顺序ETH→SOL→BTC；被占用的事件不排队。 |
| 暂不增加 | EMA/RSI/SMA、量比、资金费方向、OI、订单流、波动分位过滤、损失后停盘优化、maker费用优惠。 |

止损和仓位不是同时随意指定的两个旋钮。近似地，设止损价格距离为`s`、预留成本为`c`，名义`N≤r/(s+c)`，再受`N≤2E`约束。精确计算要处理入场/退出价格及费率，不能重复扣滑点。

实际风险预算是上限，名义上限或向下取整会让风险更低。信号不是必须交易的指令；不满足可执行条件时可以不做。

## 为什么这样设计，以及没有证明什么

较长结构首次突破是唯一方向假设。它与用户“顺势、不等回踩”一致，减少一小时小区间反复触发的可能，但**并不证明后面四小时大概率延续**。不给它叠加大量状态门，是为了知道到底哪项假设失败或成功。

账户目标和币价目标不同。设实际名义倍数`g=N/E`、净账户目标`T`，忽略小的非线性和资金费，所需有利币价变动约为`T/g+往返成本率`。例如110USDT账户、名义220USDT、目标净赚1.1USDT，在往返成本0.16%的假设下，约需币价有利变动0.66%。这只说明目标如何换算，**不说明胜率或净期望会提高**。

若实际平均盈利1.1USDT、平均亏损1.65USDT，盈亏平衡胜率是60%；若平均亏损5USDT，则约82%。风险预算不是实际平均亏损，TIME退出会改变两者，必须从回放逐笔计算。不能将止损放远、扛单或提高名义仓位当成预测优势。

## 成交与成本约定

- 正常成本假设：单边手续费5bps、滑点3bps；压力假设：单边各10bps。它们不是用户实际费率，也不承诺历史可成交水平。两种制度各自完整运行同一规则，包含风险定仓和净止盈目标计算，不把它叫同持仓纯扣费。
- 主版本双边按taker建模。maker挂单穿价不保证自己的队列成交，未来若研究需另建未成交/部分成交/回退模型。
- 普通柱触TP，以目标参考价施加一次不利退出滑点；有利开盘跳空不给额外改善。止损跳空按更差开盘价。5M同柱TP/SL都可达按stop-first；这些是OHLC顺序不足时的约定，不是真实逐笔顺序重建。
- 资金费按历史实际时间与方向符号；TP只能使用已经发生的资金费调整，不能偷看下一次结算。资金费改变阈值后不允许在柱外虚构成交。
- 历史tick/lot/min-notional、资金费制度、mark与价格数据完整性均需先审计；若历史规则不可得，只能叫执行情景，不能通过真实可执行性验收。
- 真正接入前另需持仓保护与订单状态监控；小时邮件不是止盈止损风控。本轮不接入、不采集当前行情、不自动下单。

## 如何检验方向优势

每个有效事件建立独立信号单和反向镜像单。同币、同一时刻、同一市价参考，各自承受正确方向的入场滑点；使用共同数量、共同风险预算、相同绝对止损距离、同一净目标与4小时期限。镜像止损围绕镜像方自己的实际成交价设置，资金费按各自方向计算。

随机方向基准为两单净收益均值，不假设随机应当有某个理论胜率：

`Δ = R_signal − (R_signal + R_mirror)/2`，其中`R=净PnL/共同预定风险预算r`。

它检验**在这些事件时点，信号方向是否优于随机选方向**；不证明该入场时点优于随机时点，也不证明48小时是最佳周期。

主事件研究固定参考权益110USDT，不复利、不因某影子提前平仓改变后续事件集合；允许不同事件重叠，但不能将其加总为实际资金曲线。共同参考p已经越过结构止损的事件同时排除两个方向，按多空分别报告数量；主要结论只适用于到达时止损仍有效的事件，不能外推为所有原始突破。最小单取整问题另在账户层验证。主要检验按UTC周一00:00开始的日历周，将所有币一起重采样10000次，跨周持仓归入入场周；固定种子20261124，报告双侧95%百分位区间。同小时跨币事件仅算一个描述簇，簇数不是独立样本数。

账户层另做按时间顺序的单仓、实际取整和权益变化回放。事件方向优势成立而账户收益为负或不能下单，仍不能用于交易。

## 预先约定怎样算通过

| 层次 | 预设标准；均为研究者选择，不是保证 |
|---|---|
| 有方向优势且扣费可盈利 | 正常成本平均净R与配对Δ的95%区间下界都>0；压力成本平均净R点估计≥0。 |
| 不靠一个币或一年撑住 | 2024、2025的净R和Δ分别点估计为正；剔除任一主币后的两项点估计仍为正。 |
| 账户可执行 | 正常成本账户净收益>0、最大回撤≤15%；历史交易规则可核实，完整披露不能成交/缺失/取整覆盖率。15%是研究筛选值，不是用户已同意的实盘回撤容忍度。 |
| 用户高胜率目标 | **账户层实际执行交易的净盈利胜率点估计≥65%**，同时报告区间、实际盈亏平衡胜率以及“净赚1%目标达标率”。事件层胜率只能诊断，不能代替单仓取整后的账户交易达标。账户有效样本不足则仍为证据不足。65%是建议研究目标，未来不保证。 |

只有全部满足，才支持进入下一阶段验证，仍不直接上线。若有正edge但胜率不到65%，写“高胜率目标未达”；净R上界<0或Δ上界≤0，则拒绝这一固定规格；其余跨零/不足/执行假设未解决时如实写“证据不足”或“可执行性未达”，不继续切分找正组。样本不足不能证明所有短期趋势策略无效。

额外解释项只报告、不据此增加过滤：止损距离/价格的分布、名义2E上限命中率；正常/压力成本下各自的下单覆盖率。它们用于解释失败原因，不能事后变成选参依据。

必须区分三项：到期方向命中率、先达到净目标的比例、所有退出中净盈利比例。超时赚0.1%只能算净盈利，不能算完成净赚1%的目标。
